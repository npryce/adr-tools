# Global Project Rules and Skills

This project uses structured documentation and AI agents as coding partners.
Depending on the requested task, you must consult the detailed instructions in the `.agents/skills/` folder.

## 📌 Available Skills (Read before acting):
- **Add/Configure ADR CI**: Read the file `.agents/skills/setup-ci-adr/SKILL.md`

## ⚙️ Universal Guidelines:
- Always generate the `toc.md` file when creating new ADRs.
- Do not modify old ADRs (already approved markdown files). Instead, create a new one that supersedes the previous one.
